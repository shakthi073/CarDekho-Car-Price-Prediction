# CarDekho Used Car Price Prediction

An end-to-end machine-learning project that estimates the selling price of a used car in India from its age, kilometres driven, mileage, engine capacity, maximum power, number of seats, seller type, fuel type and transmission type. A Flask web application provides a simple interface for making predictions.

## Project objectives

- Explore and understand used-car listing data.
- Clean the data and prepare numerical and categorical features.
- Compare regression algorithms.
- Tune a Random Forest Regressor and evaluate it on a held-out test set.
- Export the trained model and serve predictions through Flask.

## Dataset

The notebook downloads the CarDekho dataset from:

`https://raw.githubusercontent.com/manishkr1754/CarDekho_Used_Car_Price_Prediction/main/notebooks/data/cardekho_dataset.csv`

The source notebook describes 13 original columns:

| Feature | Description |
|---|---|
| `car_name` | Full car name |
| `brand` | Manufacturer |
| `model` | Model name |
| `seller_type` | Dealer, Individual or Trustmark Dealer |
| `fuel_type` | CNG, Diesel, Electric, LPG or Petrol |
| `transmission_type` | Automatic or Manual |
| `vehicle_age` | Vehicle age in years |
| `km_driven` | Distance driven in kilometres |
| `mileage` | Mileage in km/l |
| `engine` | Engine capacity in cc |
| `max_power` | Maximum power in bhp |
| `seats` | Number of seats |
| `selling_price` | Target price in Indian rupees |

The notebook's feature-engineering section drops `car_name`, `brand` and `model`, applies one-hot encoding to categorical fields and uses the remaining 16 encoded features. The training script keeps this feature layout so it is compatible with the web form.

## Preprocessing and feature engineering

The notebook explores missing values, summary statistics, distributions, box plots, relationships with selling price, categorical associations and feature importance.

The reproducible training script:
1. Downloads the dataset if it is not already in `data/`.
2. Removes duplicate rows.
3. converts expected numeric columns to numeric values.
4. Removes rows with missing required values, non-positive target prices or negative vehicle ages.
5. Drops `car_name`, `brand` and `model`, as in the original notebook.
6. Applies one-hot encoding to seller type, fuel type and transmission type.
7. Uses the resulting 16 input features to predict `selling_price`.

Outliers are explored in the notebook. The training script does not apply an undocumented outlier-removal rule; extreme values are retained unless they fail the basic validity checks above.

## Models

The notebook compares:
- Linear Regression
- Support Vector Regression
- Decision Tree Regressor
- Random Forest Regressor
- Ridge Regression
- Lasso Regression

It then tunes Random Forest with `RandomizedSearchCV` (100 sampled parameter combinations, 3-fold cross-validation, random state 42).

## Setup and run

Python 3.10 or newer is recommended.

### 1. Create and activate a virtual environment

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Download data, train and export the model

```bash
python train_model.py
```

This step downloads the dataset (internet connection required), trains and tunes the model, then creates `best_model.pkl` and the evaluation files under `artifacts/`.

### 4. Start the Flask application

```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser and enter the car specifications.

## Results and insights from the notebook

- The notebook records 15,411 rows in its modelling dataset and 13 original dataset columns.
- The target variable is `selling_price`; this is a regression problem.
- Vehicle age and kilometres driven show a negative relationship with selling price in the notebook's visual analysis.
- Engine capacity and maximum power are important numerical predictors.
- The notebook's Extra Trees feature-importance analysis identifies maximum power as its highest-importance feature.
- Maruti is the most frequent brand in the notebook's data exploration, while Hyundai i20 is the most frequent car name.
- Automatic cars have a higher average selling price than manual cars in the notebook's analysis.

## Limitations and future improvements

- Brand and model are omitted in the notebook's selected feature set, although the EDA suggests they may influence price. Future work can compare models that include brand/model information.
- Add stronger domain-specific validation for impossible or unusual vehicle specifications.
- Evaluate a log-transformed target or robust approaches for the right-skewed price distribution.
- Add residual plots, prediction intervals and cross-validation reporting.
- Compare the tuned Random Forest against gradient boosting models.
- For production deployment, use a production WSGI server, environment-based secrets, request limits and model/version tracking.

## Important notes

- `best_model.pkl` is generated locally by `python train_model.py`; it is not included in the source ZIP before training.
- Pickle files should only be loaded from trusted sources.
- This is an educational estimate, not a formal vehicle appraisal.
